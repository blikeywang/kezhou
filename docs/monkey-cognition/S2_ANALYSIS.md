## 2. 五种图分别说明什么

| 图 | 可直接读到 | 不能直接推出 |
|---|---|---|
| 异动大单流 | 入选 ticker、Call/Put 柱形相对大小、坐标档位、灰色 Vol | 谁交易、主动买/卖、开/平仓、净资金、筛选模型公式 |
| ETF 日内流 | QQQ/SPY/IWM 等入选流的两侧分布 | NQ/ES 实际期货链或精确指数目标 |
| 个股日内流 | 该图筛选口径下的个股两侧活动 | 全市场统一口径资金、全体合约 OI 变化 |
| 金额 Top20 | 名称中的标的/类型/行权价/到期日，展示金额和量 | 多腿净成本、账户规模、真实盈亏比 |
| 成交量 Top20 | 展示量排序及对应金额 | 最大资本承诺、净看多规模、与另一表可直接相加的唯一交易 |

Call 不等于买入看涨开仓；Put 不等于买入看跌开仓。可能有卖出、平仓、对冲或多腿组合。供应商若宣称已过滤某类交易，也只记录为供应商口径；截图无法独立验证过滤结果。

横轴金额档位会从 5M/10M/20M 切换到 50M，不能跨日比较像素长度当成交额增减。灰色 `Vol` 与金额是不同量纲。**截图未说明该“成交量”是否逐笔数量、合约日内累计量或其他统计量，必须保留为 `displayed_volume`。** 不直接用金额÷该量÷100推成交价格。表题中的“大盈亏比”是供应商标签，不是我们已算出的收益/止损比。

## 3. 提取与校对

建议未来入库字段（当前为设计，不是已完成导入器）：

```text
session_date, date_basis, source_image, image_sha256, received_at
chart_type, ticker_raw, ticker_canonical, mapping_status
option_type, strike, expiry, rank
displayed_volume, displayed_amount_usd, axis_scale
bar_comparison, extraction_confidence, duplicate_group
coverage, unknown_fields, reviewer_note
```

逐图保留原文字段。先核对日期、ticker 和小数行权价，再核对到期年份、千分位、K/M 单位。识别不清留空并标注；长柱没有数值标签时只写“Call 较大/Put 较大/接近”，不伪造精确金额。最小圆点可能是绘图最小宽度，不能当成已知正金额或精确比例；没有画柱也不一定代表全市场零成交。

标准化 ticker 前核对产品身份，尤其 SPCX 等复用/未核实标签。先保留原文，不能为迁就行情接口静默改成另一只证券。使用行情查询时单独记录代码映射和证据。

## 4. 去重和汇总

一个合约可在金额榜、成交量榜重复出现，也可在同一表多次出现。相同合约键不能证明相同事件；不同展示量也不能证明不同交易。缺少时间戳、事件 ID、交易所或序号时：

1. 每张图每行保留为“观察记录”。
2. 用 `(日期, ticker, 类型, strike, expiry)` 建疑似重复组。
3. 金额与成交量双榜做交叉定位，**不双重累加**。
4. 无事件证据时不合计重复行；只说明“多行出现”及列出的范围/代表记录。
5. 图中总柱、异动筛选、两张 Top20 是不同统计层，不能相加成资金总额。

例如 09-03 的 `NVDA-CALL-230-2026-09-04` 在成交量榜重复出现；不能据此断言多笔互不重叠的百万张买开仓。09-10 的 AAPL 同行权价重复记录同理。

## 5. 先分时点，再判断证据

每一批先建立三组：很短期限（日内/近几日）、数周至数月、远期期限。分组是研究阅读方式，边界可按用户任务调整，但必须写出实际到期日/DTE。远期大额记录不能直接证明次日走势；已到期合约退出后续可执行观察池，保留在历史证据里。

当日信息与后续验证分开：

- **当日共振**：同日已知期权图、价格表现、成交量或其他体系的关系。
- **后续验证**：之后的价格、下一次 OI、更新图是否延续。明确这是事后观察，不能写成当时已知。
- **缺失**：没有某一天、只有旧日行情、合约失效、时区/身份不明时，不补造。

普通 `--date` 只改变报告标签，不保证从最新 JSON 读取的数据都是当时可得。要做回测，需冻结每一来源的 point-in-time 快照和当时可用时间。

## 6. 价格与独立期权核对

行情必须来自另一个具名、日期匹配的来源，保留正常时段与盘前盘后口径。只得到前一天价格时标旧值；不把缓存改成截图日。

```text
daily_return_pct = (close/previous_close - 1)*100
gap_pct = (open/previous_close - 1)*100
close_location = (close-low)/(high-low)  # high==low 时缺失
option_day_return_pct = (last/previous_option_close - 1)*100
```

期权日涨跌不是从 S2 提示到收盘的收益，last 也不是可成交价。跨拆股/复权/不同币种或交易时段不能直接计算这些比率。

再看全市场 P/C、IV、实际 delta、同一合约 ΔOI、bid/ask 和成交时间，逐项标覆盖。Longbridge 全市场日聚合与 S2 筛选量口径不同，数值不相等不是必然错误。ΔOI 需真正不同结算日且相同合约；成交量/OI 高不代表新资金。只有具名净持仓模型才能讨论净 dealer Gamma，不能从 OI 自造。

## 7. 怎样形成研究优先级

不设计一个未经验证的“S2 总胜率”。按以下问题形成有依据的顺序：

1. 身份、日期、单位是否可靠？先淘汰无法确认的输入。
2. 异动图、个股日内图、单笔榜是否在**相同期限**上相互支持？同源多个榜只算互相核对，不能装作多个独立体系。
3. 标的价格有没有同向响应？若期权偏向与价格冲突，保留背离。
4. 是连续多日独立观察，还是重复一份图/同合约累计记录？缺日不称连续。
5. 大类 ETF、S1、趋势/场外与个股是否冲突？个股偏强和大盘风险可以同时存在。
6. 下一次哪些事实能确认或推翻？有效价格结构、真实 OI 日、成交方向证据与风险窗口分别列出。

建议输出三档文字：`优先复核`（证据相对完整）、`观察/背离`（支持与反证并存）、`暂不判断`（缺失或身份/时点不明）。这是人工排序，没有自动分数或概率含义。

## 8. 续更输出模板

```text
报告生成时间 / 时区：
图片数据日 / 日期关联依据 / 缺图与缺日：
主要观察：
  事实：哪张图、哪行、何种期限、展示量/金额或定性柱形
  解释：可能含义及不能识别的部分
  反证：其他图、价格或独立体系的冲突
  下一步：待核实数据与失效条件
大类背景：ETF 与个股关系
优先复核 / 观察背离 / 暂不判断：
进场止损：是否存在独立有效结构；没有则明确无可执行价位
风险窗口：到期、财报、宏观事件（使用最新事件时联网核实）
缺失输入与旧值：
研究用途，非投资建议
```

不能把行权价写成现价目标、进场位或止损；不能仅凭“有大单”补上收益率预测。后续若实现自动提取，先做带人工校对的结构化数据、重复组和缺失状态，再讨论排序模型。
