## 结论形成顺序

先确认数据身份和新鲜度，再看大类背景与同向证据；随后检查形态、价格响应、进场止损和失效条件；最后应用账户及市场风险上限。每个结论写明数据日和来源，缺失项放在结论旁边。出现背离时保留双方证据，不能为了得到单一方向删掉矛盾数据。

| 层 | 输出 | 能支持什么 |
|---|---|---|
| 输入 | 日期、来源、覆盖、错误状态 | 能否使用这条数据 |
| 方向 | S1 支持分 −3 至 +3 | 同向研究排序，不是胜率 |
| 形态 | 非冲浪、形成中、价格待确认、确认 | 原始 Buy 是否符合结构与连续出现条件 |
| 执行条件 | L0/L1、入场、止损、缺失条件 | 是否具备讨论执行的价格条件 |
| 期权 | 异常分、合约热点、ΔOI、时序 | 哪些活动值得继续查，不能证明买开仓或机构身份 |
| 风险 | 禁止新增风险/降低预算/覆盖警告 | 收紧风险；不能因某层偏多突破上限 |
| 展示 | 报告、移动端仪表、场外图表 | 解释结果；展示分数不是独立证据 |
