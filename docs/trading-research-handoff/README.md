# 每日交易研究流程：Claude 接手 README

交接基线：2026-11-08，时区 Asia/Singapore。本文说明本机“猴认知分析”项目的**实际实现、数据来源、研究方法和更新顺序**，不是当日行情报告，也不证明策略有效。

## 先读结论

这是“接收信号 → 核对来源 → 筛选结构 → 交叉验证 → 风险降级 → 研究报告”的流程，**不是交易机器人**。没有任何模块获准替用户下单。

最重要的五个边界：

1. **没有证实 S1 的底层就是 ZigZag + RSI。** 用户提供过相似图和重绘现象描述；现有项目消费 S1 清单，并不拥有供应商源码。冲浪规则是本项目自己定义的过滤器，不是 S1 复刻器。
2. **现有“一股回测”不是逐次加仓策略。** 实现持仓状态为 `-1 / 0 / +1`；同向重复 B/S 被忽略。用户最初“每个 B 买一股、每个 S 空一股”的累计版本尚未实现，不能拿已有结果回答那个策略的收益。
3. **日线信号日、首次发现时间、确认时间、可成交时间必须分开。** 后来看到的历史 B/S 不能假设在当根K线低点/高点已经知道；历史截图与事件响应不等于可成交收益。
4. **“完整入场条件”是研究规范，不代表代码已经完全强制执行。** 已发现 L1 字段接口、账户门控和日期检查等缺口，详见[已知限制](docs/KNOWN_LIMITATIONS.md)。在修复并复测前，不应把 `actionable` 等字段直接接到订单端。
5. **此 GitHub 目录只交接文档。** 不含账户、密钥、券商原始行情、付费 Desk 原文，也没有把本机整套研究源码搬进公开仓库。Claude 若要实际运行，仍需访问本机研究目录或另行获得安全的源码迁移授权。

## 分析思路：先判断能不能信，再判断值不值得看

1. **来源与身份**：核对代码、交易所、产品类型、币种；`.US`、港股前导零等别名先统一。反向/杠杆ETF不能只看买卖方向而忽略经济敞口。
2. **时序与完整性**：明确是完整清单还是仅Buy。检查缺页、相邻快照、闭合K线、复权口径和实际数据日。缺失不补成0。
3. **结构筛选**：原始B不等于买点；冲浪关注下跌后小幅震荡、不再下破，再等信号保留和价格守位。宽幅上蹿下跳不算安静震荡。
4. **交叉证据**：趋势/场外是否同向，13买点是否给出当前、可核验的结构坐标。没有覆盖不是反对，也不是支持。
5. **风险与替代解释**：区分现有持仓风险和新开仓条件；期权成交可能是保护、平仓、备兑或组合腿，不由单一P/C推断机构意图。
6. **条件表达**：输出“观察什么、何时升级、何时失效、缺什么”，不输出确定性上涨预测。报告与订单授权严格分离。
