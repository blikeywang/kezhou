## 一、先分清“知道什么”和“推测什么”

每条重要结论只能归入以下类别之一，并带来源和数据时间：

- `verified_fact`：已在相应原始来源核对的事实。来源范围有限时也必须注明，例如“该交易台客户群”。
- `reported_claim`：作者转述高盛、野村、摩根大通等观点，原始报告/模型尚未取得。
- `calculated`：由具名、同口径输入与公开公式算出的结果。
- `scenario`：带前提的预测、模型流量或目标区间，不是实际订单。
- `judgment`：基于上述证据给出的条件式研究判断，须同时列反证。
- `missing`：缺失、过期、受权限限制或读取失败，不可填零。

“看到该文章写了某数值”只验证了作者的表述，不等于独立验证该机构模型。

## 二、每次收到 Desk 链接的步骤

### 1. 读取原文，建立时间轴

记录文章标题、作者、发布时间、原文链接、文章主要复盘的美东交易日、实际读取时间。视频必须看字幕/转录或相关画面，不能仅凭标题分析。截图中的数据、正文和作者自己的推测分开记录。

优先读用户提供的原页。普通网页读取失败时，可在已授权浏览器中读取可见正文；遇到登录、验证码、权限或付费限制，遵守访问边界，不能绕过。无法取得内容就请用户提供文本或截图，并明确说明未读全文。

### 2. 拆出证据，不急于选 Call / Put

分别整理：宏观催化、财报/资本开支、主动资金、CTA、波控资金、杠杆 ETF、做市商对冲、波动率、期权大单、技术结构。每组保存时间范围、单位、覆盖对象和条件。

判断哪些是新增事实、哪些只是重复昨日观点、哪些已被后续行情削弱。文章发布后若又过了一整个交易日，必须优先补查后续行情。

### 3. 核查外部事实与最新行情

- 价格/日 K /候选期权：优先 Longbridge Securities；引用时写“数据来源：长桥证券”。
- 财报、资本开支、公司事件：公司 IR、公告、SEC 文件。
- 非农/CPI/FOMC/交易时间：BLS、Federal Reserve、交易所。
- 拆股及期权调整：基金发行人/公司公告、OCC 或交易所通知。
- 新闻用于说明市场解释，不能把“担忧监管”写成“新法规已生效”。

正常比较池为 SPY、QQQ、SMH；SOXX 是另一只半导体 ETF，不能与 SMH 混用价位。按文章需要补充 RSP、云厂商或权重股，不无边界扫描全市场。

### 4. 区分报价时段

同时保留正规交易、盘前、盘后、隔夜的价格与时间戳。选择与报告时点匹配的最新有效记录，不简单依靠字段存在与否。

特别注意：

- 主字段 `last` 可能仍是上一个正规交易日收盘。
- `pre_market` 可能留着昨天的盘前数据；一定检查其时间。
- 盘前涨跌通常相对于最近正规收盘计算，不照抄主字段昨日涨跌。
- 周末的最新收盘是历史有效数据，不是“周末实时价”。
- 缺少行情时间戳时不得称为已确认实时报价。

### 5. 先判断市场结构，再判断合约是否合适

将“大盘上涨”“科技相对走强”“半导体确认”“期权值得买”拆成四个问题。

SPY 较分散；QQQ 对大型成长股更敏感；SMH 更集中于半导体。具体持仓和权重可能变化，涉及精确比较时必须读发行人的当期资料。不能固定认为其中一个永远更好。

典型背离包括：指数上涨但半导体弱、QQQ 上涨但只有少数权重拉动、指数平稳但成分股剧烈分化、价格上涨而资金流主要为回补。相对强不等于绝对会上涨。

### 6. 给出条件式候选，允许“不交易”

此前对话用过以下观察框架，**未做胜率回测，不是自动买卖规则**：

- 重大事件公布后，再观察正规开盘最初 30 分钟。
- 反弹候选：闭合 5 分钟 K 线站在当日正规时段 VWAP 上方，突破开盘区间后回踩守住，并有相关板块参与。
- 弱势候选：冲高失败、跌回 VWAP 下方，反抽不能收复，相关板块同步转弱。
- 条件冲突、盘口缺失、事件结果未出、不能说明失效位置：保持观察。

“回踩守住/反抽失败”必须在报告中说明观察了哪几根已闭合 K 线；不能在回看结果后临时改变定义。这里不冒充原项目的 13 买点引擎，也不自动授予 L1。

失效位优先基于标的结构；期权百分比止损受价差、IV、跳空影响，不能承诺按某百分比成交。不在缺少现时 K 线和盘口时编造精确进场/止损。

### 7. 若讨论具体期权，逐项核查

必须核实标的、到期日期及合约交易截止时间、Call/Put、行权价、合约乘数、调整状态、买卖报价及时间、价差、成交量、OI 数据日、IV、可用 Greeks。

- `last` 是历史成交，不是现在可以买入的 ask 或卖出的 bid。
- 合约价格低不代表风险收益好；远虚值和临近到期需要特别解释。
- 观点正确也可能因时间损耗、波动率下降或涨跌幅不足而亏损。
- 一般长权利仓位可损失全部权利金；价差还要考虑提前指派、到期执行和腿不完整的风险。
- 预算是用户本次确认的最大可承受损失，不是必须花完的额度；不要因预算小不断选更远虚值。
- 不根据讨论过某合约就推定用户已经成交，不把个人预算或持仓写入公开仓库。

## 三、解释 Desk 数据时的硬性限制

### 机械资金

| 类型 | 解释边界 |
|---|---|
| CTA | 条件式趋势模型；区分上涨/横盘/下跌情景、未来一天/一周/一月、美国/全球 |
| Vol control | 风险目标和波动率估计导致的仓位变化；滞后执行时间必须来自原模型，不能一概认定 T+1 |
| 杠杆 ETF | 当日再平衡估算不等于次日同额卖盘；多/空杠杆产品、资金流和已有对冲均影响结果 |
| Dealer Gamma | 净持仓符号和模型来源必须可审计；负 Gamma 可放大上涨或下跌，正 Gamma 不等于方向看多 |

不同机制、时间窗和覆盖范围的金额不能直接相加。提前交易、对冲重叠和价格路径会改变实际流量。`flat` 通常是空仓/中性，不应擅自翻译为做空。

### 波动率与历史统计

- 恐慌分数不是见底概率；历史极端分位不保证立即均值回归。
- VIX 是 SPX 期权相关的波动指标，不是某张 QQQ Call 的 IV，也不是上涨/下跌概率。
- VIX 曲面分解不能直接识别现货买家；Call skew 下降不等于股票没有买盘。
- VIX 期限倒挂说明近端风险定价较高，不保证下跌会很快结束或继续。
- 隐含波动范围不是确定的支撑阻力，不代表区间两端都会触及。
- 历史胜率必须有样本、事件定义、观察期限、重叠样本、最大不利波动、费用和样本外检验；缺这些只引用为未复核统计。
- 10–25 个交易日的统计，不能直接支持两天到期的期权。

### 期权大单

区分 buy-to-open、buy-to-close、sell-to-open、sell-to-close、多腿、滚仓和备兑。买 Call 可能是在平掉空 Call，卖 Put 可能承担接货风险；大单可能仅为已有股票保险。成交额不等于净资金流，Volume 不等于新增 OI，OI 不提供交易者身份或做市商净方向。

## 四、采集入口（只读）

先执行 `longbridge --help` 及相应子命令 `--help`，再按当前版本运行。以下模板不含账户访问和下单命令：

```bash
longbridge quote SPY.US QQQ.US SMH.US --format json
longbridge kline QQQ.US --period day --count 60 --adjust forward --format json
longbridge kline QQQ.US --period 5m --count 100 --session intraday --format json
longbridge news QQQ.US --count 5 --format json
longbridge news detail NEWS_ID --format json
longbridge option chain QQQ.US --format json
longbridge option chain QQQ.US --date YYYY-MM-DD --format json
longbridge option quote EXACT_SYMBOL_FROM_CHAIN --format json
longbridge depth EXACT_SYMBOL_FROM_CHAIN --format json
```

`NEWS_ID`、日期和合约符号必须由实际查询替换，不可照抄占位符。链表只用于发现到期日/行权价/符号，不能假定它含完整报价与 Greeks。逐合约报价有时也不含 Greeks，应标缺失；如另用定价模型必须单独标记 modeled 并披露假设。

OpenAPI 行情权限与 App/Web 权限不一定相同，OPRA 期权权限可能需要额外订阅。遇到缺权限，不自动购买、不升级授权。

JSON 输出曾在前后混有版本提示。保留退出码、stderr 和原始响应于本地私有审计层；解析失败应报告，不用空数组冒充成功。日志清理告警与行情失败分开记录，不为消除告警删除用户日志。
