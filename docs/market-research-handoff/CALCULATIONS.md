# 计算逻辑、单位与边界

版本：2026-11-08。所有例子为合成数据，不是当前行情、成交建议或用户仓位。

## 0. 符号与计算纪律

`S` 为标的价格，`K` 为行权价，`p` 为每股权利金，`m` 为合约乘数，`n` 为合约张数，`F` 为明确范围内的费用总额。价格用同一币种；正数损失上限和带正负的损益分开命名。

标准美股股票/ETF 期权常见 `m=100`，但必须读实际合约资料，不能对调整合约或期货期权一律乘 100。所有期权到期公式假定合约完整、相同到期和有效执行；不是盘中公允价值或实际可成交价格。

缺失值为 `null/missing`，不可填 0。分母为零、非有限数、跨币种、跨复权口径或时间明显错配，均拒绝计算。

## 1. 本对话实际使用过的基础计算

### 1.1 涨跌幅、距离与相对表现

```text
涨跌幅(%) = (当前价 / 基准价 - 1) × 100
距行权价的有符号变化(%) = (K / S - 1) × 100
从高点回撤(%) = (S / 区间高点 - 1) × 100
两标的收益差(百分点) = 标的A涨跌幅(%) - 标的B涨跌幅(%)
两标的相对价格比的变化(%) = ((1+rA)/(1+rB) - 1) × 100
```

最后一式的 `rA/rB` 用小数，不能与百分点差混称。距离行权价不是盈亏平衡距离；已经价内时有符号距离可为负。

例：100 跌至 80 是 -20%；80 恢复到 100 要 +25%。A 涨 2%、B 跌 1%，超额表现为 3 个百分点，相对比值涨幅约 3.03%，不是同一个数。

盘前/盘后涨跌的基准应为该扩展时段对应的最近正规收盘，需核对日期。正规主字段昨日涨跌不可冒充今天盘前涨跌。

### 1.2 成交量比较

```text
相邻交易日量比 = 今日完整正规成交量 / 前一交易日完整正规成交量
RVOL_N = 今日完整正规成交量 / 前N个完整正规交易日成交量均值
```

二者不等价。盘中只能和历史相同已过时长比较，否则注明不可比；不能把开盘半小时与昨日全天相除当异常量判断。

### 1.3 权利金、到期损益和盈亏平衡

```text
买入成本 = p × m × n + 买入费用
Long Call 到期损益 = [max(S_T-K,0)-p] × m × n - F
Long Put 到期损益  = [max(K-S_T,0)-p] × m × n - F
Call 到期盈亏平衡 = K+p+F/(m×n)
Put 到期盈亏平衡  = K-p-F/(m×n)
```

盈亏平衡式需说明 `F` 是否包含预期平仓/行权费用。未考虑费用时标注 gross。到期前可以在未跨过行权价时获利卖出，但依赖实际市场报价；不能拿到期损益公式推算盘中收益。

例：买一张 `K=105, p=2, m=100` 的 Call，另有总费用 1 美元。到期 `S=110` 时损益为 299 美元，盈亏平衡 107.01，最大权利金损失为 201 美元。

### 1.4 牛市 Call 借记价差

同到期、同张数，买低行权价 `K_L` Call、卖高行权价 `K_H` Call：

```text
d = 买入腿权利金 - 卖出腿权利金
w = K_H-K_L
到期损益 = [min(max(S_T-K_L,0),w)-d] × m × n - F
最大损失 = d×m×n+F
最大净利润 = (w-d)×m×n-F
盈亏平衡 = K_L+d+F/(m×n)  （可实现盈利时）
```

正常借记结构要求 `0<d<w`。多腿必须使用同一时点、可比市场的报价。保守买入估算为长腿 ask 减短腿 bid，但它也不是组合保证成交价。

例：100/110 Call spread，净付 3，每张最大到期支付额 1,000、最大毛利润 700、成本 300。支付额/成本为 3.33 倍，净利润/成本为 2.33 倍，不得混称。

### 1.5 熊市 Put 借记价差

买高行权价 `K_H` Put、卖低行权价 `K_L` Put：

```text
d = 长Put权利金 - 短Put权利金
w = K_H-K_L
到期损益 = [min(max(K_H-S_T,0),w)-d] × m × n - F
最大损失 = d×m×n+F
最大净利润 = (w-d)×m×n-F
盈亏平衡 = K_H-d-F/(m×n)  （可实现盈利时）
```

更低行权价卖 Put 会限制保护/盈利；提前指派、到期 pin risk 或只剩单腿可能产生额外股票敞口。名义最大损失不代表在错误执行情况下无额外风险。

### 1.6 Put-spread collar 的尾部缺口

持有 1 股、买 `K_P` Put、卖更低 `K_L` Put、卖更高 `K_C` Call，且 `K_L<K_P<K_C`。

忽略期权净成本，组合到期价值为：

```text
V(S) = S + max(K_P-S,0) - max(K_L-S,0) - max(S-K_C,0)
S >= K_C        : V=K_C
K_P <= S < K_C  : V=S
K_L <= S < K_P  : V=K_P
S < K_L         : V=S+K_P-K_L
```

实际损益还需减去原股票成本、期权净支出和费用。跌破 `K_L` 后亏损重新随标的下跌扩大；卖低行权价 Put 不是保护更深尾部。零权利金成本不等于零风险。

卖出 Put 的到期盈亏平衡 `K-p` 只是该仓位成本口径，不是市场保证支撑位；最大毛损失在标的归零时为 `(K-p)×m×n`。

### 1.7 拆股与调整

普通 `r:1` 拆股的基础经济换算：`新股数=旧股数×r`，`新价格=旧价格/r`，拆股本身不改变总市值。期权必须以 OCC 的具体调整通知为准。

SOXX 的 2026-11-05 历史案例有官方 3:1 拆股和期权调整通知：旧 450/360 对应新 150/120。此处只保留方法案例，不作为现在的价位。其他公司行动可能改变 deliverable、乘数、代码或现金部分，禁止仅凭“看起来差三倍”自动修正。

### 1.8 单位

- 1 billion 美元 = 10 亿美元；1 million 美元 = 100 万美元。
- 1 bp = 0.01 个百分点；100 bps = 1 个百分点。
- IV 从 20% 到 25% 是 +5 个波动率点，不是 +5% 的相对变化。
- 1.43% 的区间近似：`[S×(1-0.0143), S×(1+0.0143)]`；不代表两端都会触及。

## 2. 为后续更新定义的扩展公式

以下不是声称每次对话都已计算。没有足够数据就不输出；其中参考实现覆盖了 VWAP、HV、IV rank/percentile、Delta OI 和简化预期波动，其余为方法说明。

### 2.1 VWAP 与开盘区间

```text
逐笔VWAP = Σ(price_i × volume_i) / Σ(volume_i)
分K代理VWAP = Σ(((high_i+low_i+close_i)/3) × volume_i) / Σ(volume_i)
OpeningRangeHigh = 首30分钟已闭合正规K线的最高价
OpeningRangeLow  = 首30分钟已闭合正规K线的最低价
```

只用同一交易日正规交易时段。分 K 代理必须标记 approximation，不与逐笔/券商 VWAP 假装完全相同。未满 30 分钟的区间是未完成区间；盘前高低不能混入。

### 2.2 均线与 ATR（未在参考程序实现）

```text
SMA_N = 最近N个闭合收盘价的算术均值
TR_t = max(H_t-L_t, abs(H_t-C_(t-1)), abs(L_t-C_(t-1)))
ATR_N 初值 = 前N个TR的均值
Wilder ATR_t = ((N-1)×ATR_(t-1)+TR_t)/N
```

先说明复权方式、交易时段、周期和 warm-up。项目 ATR20 与日内 ATR 不可混用。ATR 仅描述价格噪声尺度，不是强平距离或胜率。

### 2.3 HV、IV 与历史分位

```text
r_t = ln(C_t/C_(t-1))
HV = sample_std(r_t, ddof=1) × sqrt(A)
IV/HV = 同单位IV / HV
IV Rank = (IV_now-min(IV_history))/(max(IV_history)-min(IV_history))×100
IV Percentile = count(历史IV < IV_now)/历史样本数×100
```

美股日收益的 `A` 常取 252，必须标明；60 个收益需要 61 个收盘价。历史 IV 必须同期限、同 Delta/moneyness、同取样时点和同来源。百分位的相等值约定为严格小于。

**禁止用 HV 历史或股价区间替代 IV 历史来计算 IV rank/percentile。** 历史 IV 全相同时 rank 无定义；HV=0 时 IV/HV 无定义。深度虚值、接近到期、零 bid 或极小权利金的反解 IV 可能很不稳定。

参考程序将历史窗口与当前 IV 分开传入；若当前值创窗口外新高/新低，rank 可超过 100 或低于 0，不静默截断。若供应商定义的窗口包括当前值，应按供应商定义构造输入并披露；不可混比两种口径。

### 2.4 预期波动（粗略尺度）

```text
年化IV简化尺度 = S×IV_decimal×sqrt(T_years)
对应相对尺度(%) = IV_decimal×sqrt(T_years)×100
ATM跨式成本比例(%) = (Call_premium+Put_premium)/S×100
```

`T` 的 calendar/trading-day 年化惯例必须与 IV 一致。跨式成本不是正态一倍标准差；有偏斜、跳空和事件风险时，不能宣称“68%一定落在区间内”。ATM跨式支付的近似到期收支平衡区间也不等于真实概率分布。

### 2.5 Greeks 一阶/二阶近似（未实现定价模型）

```text
Δoption_price ≈ Delta×ΔS + 0.5×Gamma×(ΔS)^2
                + Vega×ΔIV_vol_points + Theta×Δdays
```

此式假定 Vega 单位为每 1 个波动率点、Theta 为每一日的持有损耗。供应商若按 IV 小数单位、每年或其他口径报价，必须换算；用 Rho 时同样确认利率单位。净组合敏感度为带多空符号的逐腿敏感度乘乘数和张数。

这只是局部近似，大跳空、0DTE、早行权和极端波动下误差可能很大。Delta 不能直接叫真实到期盈利概率。Greeks 缺失时默认留空；不得把未经披露的 Black–Scholes 估计冒充实际行情。

### 2.6 P/C、OI 与 Gross 敏感度

```text
Volume P/C = Put成交量 / Call成交量
OI P/C = Put持仓量 / Call持仓量
ΔOI = 本期同合约OI - 前期同合约OI
Volume/OI = 当期成交量 / 相应OI
Gross Gamma($/1%标的变动) = |Gamma|×OI×m×S²×0.01
Gross Delta($) = |Delta|×OI×m×S
Gross Vega($/1 vol point) = |Vega|×OI×m  （Vega须已是该单位）
```

OI 可能是前一清算日而不是盘中；成交量与 OI 时间要分别标注。前 OI 为 0 时增长比例无定义，但 ΔOI 可以有值。拆股、合约更名、交割物调整后要先建立可比映射。

Gross 是无符号集中度，不是做市商净 GEX；不能由 OI 峰值自动推导 Call Wall、Put Wall 或 Gamma flip。交易所/机构净仓位方法缺失时，这些字段只能 `reported_claim` 或 `missing`。
