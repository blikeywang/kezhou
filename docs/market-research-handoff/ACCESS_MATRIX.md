## 2. 接手需要哪些独立权限

- 本地文件：由用户为 Claude 配置日报项目读取权限，以及 `data/reports/outputs` 的任务内写权限；外部两处只读参考必须保持只读。只有 GitHub 访问权限不能读到本机历史。
- GitHub：只需目标仓库的内容读取/提交能力；遵守现有分支保护，不 force-push，不改可见性，不索取组织管理员权限。
- 长桥：行情/新闻/期权所需的只读授权；OPRA OpenAPI 与 App/Web 可能不同。缺订阅就标 missing，不自动购买；无需订单和持仓接口权限来做 Desk 研究。
- TrendTrader：秘密只来自环境变量 `TRENDTRADER_API_KEY` 或本机 `config/private.json`，按配置批量/总量预算使用。
- OKX：仅风险任务需要，环境变量名称为 `OKX_API_KEY`、`OKX_API_SECRET`、`OKX_API_PASSPHRASE`；密钥只能 **Read**，严禁 Trade/Withdraw。
- IBKR/CME：仅在用户已授权时使用相关行情；没有 FOP 权限则降级 eod_actual/proxy，不申请交易能力。
- 私有站点：复用已存在的私有托管绑定；绑定 ID、token、配置不放进本包。GitHub 文档提交不等于已为 Claude 开通该站点发布权限。

不要让用户把 token、密码、Cookie 或 API secret 粘贴到公开 issue、README、日志或对话。需要权限时只说明所缺能力，由用户在安全的产品登录/环境配置中完成。

## 3. 提交前的白名单审查

本次公开包只包含以下类别：中文方法文档、公开来源 URL、相对路径定位、当前文件覆盖统计、纯离线合成公式/测试。**不包含用户预算、持仓、成交状态、账号标识、原始收费内容或私人 Notion 链接。**

不能以 `.gitignore` 代替审查：本机旧 ignore 只排除了部分敏感路径，不覆盖全部新账户/期权/手机快照。禁止 `git add .` 或全量复制整个私有项目；使用明确文件清单。

公开导出器的正则过滤不是完整隐私证明。字段白名单、逐文件 diff、人眼检查与测试必须同时使用。若新任务涉及未公开历史、账户衍生值、期权详细链、最终动作全文或 Desk 付费文本，先确认发布范围。

## 4. 故障与恢复

- 无文件权限：只完成已授权文档/公开源检查，说明具体缺少哪个目录能力，不通过其他账户或隐藏路径绕过。
- 无数据权限：保留 missing/access_denied，不捏造行情，不改用过期值冒充。
- 仓库保护/提交冲突：读取新 head，保留他人更改；按既有规则走分支/PR，不强推。
- 误公开秘密：立即停止后续发布，告知用户并撤销/轮换受影响凭证；仅删除最新文件不能擦除 Git 历史。历史重写/删除需单独确认范围，不能自行破坏仓库。
