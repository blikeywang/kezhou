Three-stage workflow · Four independent systems

三套核心工作台，外加四套独立系统

历史研究、下单决策与交易复盘继续组成原有三阶段闭环；NQ Flow 负责盘中订单流，IncomeOS 负责长期资金进入，整股版解决不能交易碎股的账户，TailTrend Lab 则用日线收盘协调尾部反转、趋势接受与风险预算。四者都不改写前三套产品的输入、输出和拒绝条件。

INDEPENDENT SYSTEM · WHOLE SHARES ONLY

IncomeOS 整股版

完整保留 IncomeOS 九个板块与同一份研究快照，但执行层只输出整数股。小账户的 SPY 核心自动使用同指数低单价 SPYM，不生成任何碎股。

  • 输入本周到账、上期余款与账户净值，输出具体标的、完整股数和预计占用现金
  • 不足一股的 QQQ 或卫星目标先汇入 SGOV，未使用现金自动滚入下次
  • Top 50、成长周期、Sell Call、Sell Put、Risk Engine 与历史归档全部保留
生成整数股操作单 → 完整股数 · IBKR 人工限价执行
INDEPENDENT SYSTEM · DAILY-CLOSE SHADOW TEST

TailTrend Lab

把“下沿收复做多、上沿管理、突破后跟随、失败后退出”写成同一套可复现状态机，再由账户、波动率和集群风险决定能否占用仓位。

  • Longbridge 前复权正常时段日线；公开站只发布派生状态，不发布原始K线
  • 下沿收复、趋势接受、突破失败、下沿破位、事件隔离与中部等待分桶展示
  • 本地压力仓位计算共享一个想法的总风险，账户输入不保存、不上传、不自动下单
开始几天影子测试 → 日线正式判定 · 盘中只做边界与硬风险提醒

Evidence language

统一证据语言，避免把不同东西混成“专家结论”

整个 TraderHome 使用一致标签，让用户一眼区分数据事实、派生统计、前向验证和教学推演。

DATA

原始或授权数据

已收盘K线、用户授权交易记录或具有明确使用权的逐笔材料。

DERIVED

派生统计

概率、Edge、相关性、回撤和行为分数；必须同时展示口径与局限。

FORWARD

前向封存验证

在结果发生前记录的计划，之后按统一规则结算；失败记录不得回删。

METHOD / DEMO

方法推演或合成演示

用于解释思路和展示功能，不能冒充专家真实交易或真实账户结果。
